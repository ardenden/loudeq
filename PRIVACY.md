# Privacy Policy — loudeq

loudeq does not collect, store, or transmit any personal data.

The app reads and writes Windows audio device settings (the "Loudness Equalization" enhancement flag and the other Windows audio enhancements) on your own machine only, using the same mechanisms as the Windows Sound control panel.

The command-line tool and the downloads from GitHub have no network functionality: they never connect to the internet.

The Microsoft Store version offers an optional in-app purchase, LoudEQ Pro. To know whether Pro is owned, and to sell it, the app uses the Microsoft Store's own licensing service; that is its only network activity. Purchases are handled entirely by Microsoft under the [Microsoft Privacy Statement](https://privacy.microsoft.com/privacystatement). loudeq receives no payment details or personal information.

Contact: https://github.com/ardenden/loudeq/issues
